## 🎯 다음 우선순위

### P1. 위시리스트 (읽고 싶은 책)
- `BookStatus` 에 `wishlist` 상태 추가
- 홈 화면 탭 3개로 확장: 위시리스트 / 읽는중 / 완독
- 검색 결과에 "읽기 시작" / "위시리스트 담기" 두 액션
- 위시리스트 → 읽는중 전환 버튼
- **예상 작업: 1~2시간**

### P2. 알라딘 가격 정보
- `BookTocService` 를 `AladinBookService` 로 확장 (TOC + 가격 + 구매 링크)
- `Book` 모델에 `priceStandard`, `priceSales`, `purchaseLink` 필드 추가
- 상세 화면에 "정가/판매가" 표시 + "알라딘에서 구매" 버튼 (`url_launcher`)
- 위시리스트와 결합 시 가격 한눈에 비교
- **예상 작업: 1시간**

### P3. 기간별 독서 통계
- 별도 "통계" 탭 또는 홈 상단 카드
- 기간 필터: 오늘 · 이번주 · 이번달 · 올해 · 사용자 지정
- 표시 항목: 완독 권수, 월별 막대그래프(`fl_chart`), 평균 완독 주기
- (향후) 페이지/독서시간 통계는 별도 추적 기능 추가 후
- **예상 작업: 3~4시간**

### P4. 소셜 로그인 + 클라우드 동기화
> 로그인만으로는 의미가 없으므로 **백엔드 + 동기화**를 함께 구축.

#### 4-1. 백엔드 셋업 (Supabase)
- Supabase 프로젝트 생성
- `books` 테이블 (user_id, 책 데이터)
- Row Level Security(RLS) 정책: 본인 데이터만 접근
- 로컬 → 클라우드 마이그레이션 로직 (기존 로컬 데이터 보존)

#### 4-2. 로그인 단계별 도입
1. **Google 로그인** (Supabase 기본 지원, 가장 빠름)
2. **카카오 로그인** (`kakao_flutter_sdk` + Supabase Edge Function으로 세션 교환)
3. **네이버 로그인** (`flutter_naver_login` + 동일 패턴)

#### 4-3. 동기화 전략
- 로컬 우선(Local-first), 백그라운드 동기화
- 충돌 해결: 마지막 수정 시간 기준(Last-Write-Wins) 또는 필드별 머지
- 오프라인 큐 (네트워크 끊김 시 변경 적재 후 재연결 시 flush)
- **예상 작업: 1~2일 (백엔드 + 3개 로그인 + 동기화)**

## 🔮 그 외 아이디어 (미확정)

- 교보문고 목차 프록시 (Supabase Edge Function) — 알라딘에 없는 책 대응
- AI 목차 추정 폴백 (Claude API)
- 일일 독서 시간 타이머 (포모도로 통합)
- 책 메모/하이라이트
- 독서 챌린지 (월 N권, 100일 챌린지)
- 친구·소셜 공유 (상용화 단계)
- 책 추천 (읽은 책 기반 큐레이션)

## 💡 의사결정 필요 사항

- **상용화 시 결제 모델**: 위시리스트 무제한? 통계 고급 기능 유료?
- **데이터 백업 정책**: 클라우드 동기화 무료 / 프리미엄 분리?
- **광고 정책**: 자기계발 앱 톤상 광고 지양 권장 → 구독제 중심
